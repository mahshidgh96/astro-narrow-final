# Astro Narrow — Persian Edition

فارسی | [English](README.md)

این یک فورک از قالب [Astro Narrow](https://github.com/tom2almighty/astro-narrow) هست که توسط tom2almighty ساخته شده. کاری که اینجا اضافه شده اینه که کل قالب رو برای فارسی و راست‌به‌چپ (RTL) آماده کردم.

## چی اضافه شده؟

اگه بخوام خلاصه بگم: این قالب دو زبانه است. یعنی سایت الان هم انگلیسی داره هم فارسی، و وقتی روی فارسی هستی همه‌چیز درست از راست به چپ می‌شینه — منو، محتوا، breadcrumb، همه‌چیز. برای فونت هم از Vazirmatn استفاده کردم که فقط توی صفحات فارسی لود میشه (صفحات انگلیسی دست‌نخورده باقی می‌مونن). تاریخ پست‌ها هم توی حالت فارسی با تقویم جلالی و اعداد فارسی نمایش داده میشه.

برای مدیریت محتوا هم از [Vault CMS](https://vaultcms.org) استفاده می‌کنم؛ یعنی مستقیم از Obsidian می‌نویسم و با یک push منتشر میشه، بدون نیاز به یک CMS جدا. بدون نصب vault-cms و فقط با داشتن ابسیدین هم میشه پست ها رو منتشر کرد. کافیه فولدر پروژه رو به عنوان یه والت در ابسیدین باز کنید.

بقیه‌ی چیزها — content collections، ساختار config، امکانات مارک‌داون — دقیقاً همونیه که توی نسخه اصلی Astro Narrow هست، پس برای اون بخش‌ها مستندات خود قالب اصلی هنوز کاربرد داره.

## راه‌اندازی

```sh
pnpm install
pnpm dev
pnpm build
```

## اگه می‌خوای یک زبان دیگه اضافه کنی

زبان‌ها رو توی `src/config/i18n.ts` تعریف می‌کنی (همون‌جا مشخص میشه هر زبان RTL هست یا LTR)، و ترجمه‌ی متن‌های رابط کاربری توی `src/i18n/ui.ts`. محتوا هم میره توی یک پوشه‌ی جدید، مثلاً `src/content/posts/fa/`.

## فایل‌های پیکربندی اصلی

- `src/config/site.ts` — اطلاعات سایت و نویسنده، منو، عرض صفحه، کامنت‌ها، آنالیتیکس
- `src/config/content.ts` — تنظیمات مربوط به نوع محتواها (پست، پروژه و غیره)
- `src/config/i18n.ts` — زبان‌ها و جهت هرکدوم
- `src/config/theme.ts` — گزینه‌های ظاهری
- `src/content.config.ts` — schema محتوا
